## What Needs To Be Done Next

### Priority 1: DeepSeek Agent Backtest (Option 1 from Path C)

The quantified veto proxy failed because it can't replicate qualitative judgment. The real test: run the actual LLM agents on historical candidates using DeepSeek V3.2 ($0.14/M input, $0.28/M output — ~$28 for a full 8-window backtest).

**Steps:**
1. Set `LLM_PROVIDER=openai` and `OPENAI_BASE_URL=https://api.deepseek.com/v1` with DeepSeek API key
2. Write a script that runs the 6 agents on each candidate at each walk-forward rebalance date
3. Cache all SIGNAL_SCORE outputs to JSON
4. Replay the backtest using cached agent scores as the ranking/veto layer
5. Compare: same 8 windows, with vs without agent scores
6. If agent scores improve WF, run shadow mode for 3-6 months

**Cost estimate:** 8 dates × 20 stocks × 7 calls × ~90K tokens ≈ 100M tokens → ~$28 at DeepSeek V3.2

### Priority 2: Longer Backtest History

The 2020-2026 window (75 months) may be too short for statistical significance. With WRDS data back to 2013, extend to 2013-2026 (156 months):
- 12 CPCV groups → 924 combinations → much more statistical power
- Need to seed price data for 2013-2019 (Tiingo or Alpaca can provide this)
- Alpha t-stat may reach significance with 2x the observations

### Priority 3: Signal Architecture Overhaul

The stress test proved the current signal stack is broken. The plan (PLAN_SIGNAL_STRESS_TEST.md) calls for:
- Drop BB, MR, RSI (redundant/wrong-sign)
- Keep OBV (only surviving signal) + SMA as gate
- ERM as primary ranker (IC t=1.60, needs more power)
- Add 13F institutional flow signal (WRDS `tr_13f.s34`, 125M rows, already accessible)

### Priority 4: Scaling Beyond liquid_10

The core problem: larger universes underperform because the ranking doesn't differentiate stocks. Two remaining approaches:
1. **13F institutional flow** — genuinely independent signal dimension (smart money)
2. **Real LLM agent scoring** — via DeepSeek (Priority 1 above)
