the AI financial analyst is a agentic solution to financial analysis. 
## Structure ##

Manager Agent 
- DCF Analyst (Morgan Stanley)
- Risk Analyst (bridgewater)
- Earnings (JPM)
- Competitive Analysis + Sector Analysis (Bain)
- Pattern Analysis (Renaissance tech)


## Flow / Use Cases ##
input an individual stock/ticker/portfolio

Manager prompts each agent to do its research with its own angle

outputs a formatted brief with risks/upside/health score
